# Development progress

## Phase 1

- Added the responsive design system and Material theme.
- Added home, colouring category, coming-soon, and locked parent screens.
- Added centralized routes and portrait orientation locking.
- Added small-phone, tablet, and navigation widget tests.

## Phase 2

- Added normalized immutable drawing strokes and pure undo/redo history.
- Added quadratic midpoint smoothing, dot rendering, pen and clear-mode eraser.
- Added committed/live repaint layers, child-friendly toolbar, and drawing screen.
- Added cached rasterization after 150 strokes, retaining 50 recent vector strokes.
- Added model, geometry, controller, and gesture widget tests.

## Phase 3

- Added local SVG parsing with `xml` and `path_drawing`.
- Added region hit testing with aspect-ratio-preserving letterboxing.
- Added colouring state, undo/redo/reset history, controller, painter, and UI.
- Added flower, house, and fish test pages plus the asset validator.

## Phase 4

- Added the asset catalog, lazy category page list, and runtime SVG thumbnails.
- Added normalized sticker placement, dragging, selection, resizing, deletion,
  and a 12-sticker maximum.
- Added sticker and category navigation tests.

## Phase 5

- Added versioned artwork models and tolerant private-file repository.
- Added atomic JSON, thumbnail, and preview writes.
- Added PNG export at 300px and 1080px widths.
- Added save actions for drawing and coloring and the local gallery.

## Phase 6

- Added persistent sound-effect settings with `shared_preferences`.
- Added built-in child feedback sounds without network or media assets.
- Added a math parent gate and a protected parent settings screen.
- Added sound-effect controls and an external privacy-policy action.

## Cartoon colouring collection

- Added a dedicated Cartoons category to the colouring book.
- Added three original, locally bundled cartoon pages: bunny, robot, and
  monster.
